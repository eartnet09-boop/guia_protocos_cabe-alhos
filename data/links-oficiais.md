# Diretório de fontes

| Recurso | URL | O que contém |
|---|---|---|
| RFC Editor | [rfc-editor.org](https://www.rfc-editor.org/) | RFCs e erratas publicadas pela IETF. |
| IANA Protocol Registries | [iana.org/protocols](https://www.iana.org/protocols) | Registros de protocolos, portas, parâmetros e tipos. |
| MDN Web Docs | [developer.mozilla.org](https://developer.mozilla.org/) | Referência web de HTTP, APIs e headers. |
| OWASP Secure Headers Project | [owasp.org/www-project-secure-headers](https://owasp.org/www-project-secure-headers/) | Referência de headers de segurança web. |
| OWASP Cheat Sheets | [cheatsheetseries.owasp.org](https://cheatsheetseries.owasp.org/) | Orientações de segurança por tema. |
| Security Headers | [securityheaders.com](https://securityheaders.com/) | Avaliação remota de headers HTTP; envia o domínio ao serviço. |
| SSL Labs | [ssllabs.com/ssltest](https://www.ssllabs.com/ssltest/) | Avaliação pública de configuração TLS; considere a divulgação do host. |
| HSTS Preload | [hstspreload.org](https://hstspreload.org/) | Verificação e submissão à lista de preload HSTS. |
| Fetch Standard (WHATWG) | [fetch.spec.whatwg.org](https://fetch.spec.whatwg.org/) | Algoritmos web, incluindo CORS e fetch. |
| OWASP Web Security Testing Guide | [owasp.org/www-project-web-security-testing-guide](https://owasp.org/www-project-web-security-testing-guide/) | Metodologia de testes web autorizados. |
